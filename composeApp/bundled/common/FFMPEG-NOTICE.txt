FFmpeg
======

Scrcpy Vwr uses FFmpeg 8.1.2 (https://ffmpeg.org/) to decode the mirrored video and, as a separate `ffmpeg`
program, to make GIFs from recordings. FFmpeg comes from the JavaCPP Presets for FFmpeg by Bytedeco
(org.bytedeco:ffmpeg 8.1.2-1.5.14), which ship it as shared libraries and an executable inside the app.

Source code
-----------
The source and build scripts used to make these FFmpeg binaries:
  https://github.com/bytedeco/javacpp-presets/tree/1.5.14/ffmpeg
FFmpeg's own source code: https://ffmpeg.org/download.html (release 8.1.2) and https://git.ffmpeg.org/ffmpeg.git

FFmpeg is not statically linked into Scrcpy Vwr: it is loaded as separate shared libraries and run as a separate
program, unmodified from the Bytedeco build above.
